# Proyecto Carrera Ciclística - Programación Orientada a Objetos (Java)

## 🚴 Descripción del Proyecto
Sistema desarrollado en Java aplicando los principios de la Programación Orientada a Objetos (POO) para modelar una carrera ciclística, incluyendo clases abstractas, herencia, constructores y métodos específicos para las diferentes especialidades de ciclistas.

## 👥 Integrantes
* **DEYBI Alexander Velasco**

## 🛠️ Estructura del Código
* `ciclista.java`: Clase abstracta base.
* `Velocista.java`: Subclase con atributos de potencia y velocidad en sprint.
* `Escalador.java`: Subclase con atributos de aceleración y grado de rampa.
* `Contrarrelojista.java`: Subclase con atributo de velocidad máxima.
* `Equipo.java`: Clase contenedora de ciclistas y gestión de tiempos.
* `Main.java`: Clase principal de ejecución.
* `CiclistaTest.java`: Casos de pruebas unitarias.
